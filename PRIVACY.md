# Privacy Policy

Galaxy Ethernet Tether does not collect, store, upload, sell, or share personal
data.

## Data Collection

The app does not collect:

- screen contents
- app usage analytics
- location data
- contacts
- messages
- browsing activity
- device identifiers for tracking
- account information

## Accessibility Service

The app uses Android Accessibility Service only to automate Samsung's Ethernet
tethering setting after user consent.

While the service is enabled, Android allows the app to inspect visible window
content needed for accessibility automation. This app limits that use to finding
and tapping the Ethernet tethering switch in Samsung Settings.

The app does not transmit Accessibility Service data off the device.

## Network Access

The app does not make network requests.

## Local Storage

The app stores only a local boolean preference indicating that the user accepted
the in-app Accessibility Service disclosure.
